# Book-Inventory-System

## Features 
- Display available books in inventory
- Validate user input (title and author matching)
- Check for book's availability 
- Display quantity available for each book
- Loop input until a valid book is entered
- Handle invalid entries with error messages

## Tools Used 
- C++
- Arrays (2D and 1D)
- Loops (for, do-while)
- Boolean validation logic
- Input handling with getline

### How it works
Books in inventory are stored in a 2D array (title, author), with its availability value stored in a 1D array as well as its copies quantity. Book Inventory menu will display and prompt the user to select a book and its author. If the book is in stock, message will display the amount of copies available.
